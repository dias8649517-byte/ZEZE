# ZEZE STYLE

Статический сайт магазина. Главная страница — index.html; фотографии и шрифты — в assets/.

## Загрузка в GitHub

1. Распакуйте архив ZEZE-STYLE-GitHub.zip.
2. Создайте репозиторий в GitHub.
3. Выберите Add file → Upload files и загрузите содержимое папки: index.html, папку assets, .nojekyll и остальные файлы. Сам ZIP загружать не нужно.
4. Сохраните файлы кнопкой Commit changes.

## Публикация через GitHub Pages

1. Откройте Settings → Pages.
2. Выберите Deploy from a branch.
3. Укажите main и / (root), затем Save.
4. После завершения публикации GitHub покажет адрес сайта.

Загружайте index.html в корень репозитория, рядом с assets/. Внутри assets/ сохраняйте исходные имена файлов.

## Возможности

Каталог с категориями, страницы товаров, корзина, команда, соцсети и шоурум. Образ недели меняется из текущего каталога по понедельникам. Корзина хранится в браузере; заказ копируется для отправки в Telegram. Онлайн-оплата не подключена.

Шрифт Marta распространяется по лицензии в OFL_Marta.txt. Эта лицензия относится только к шрифту.
